This repository is an educational deep dive into building a GPT-style language model from the ground up. The project draws inspiration from Andrej Karpathy’s “Let’s Build GPT: From Scratch” series and is backed by theoretical foundations from the seminal paper “Attention is All You Need” by Vaswani et al.


The goal of this project was  not just to replicate GPT behavior, but more so for me to understand the inner workings of transformer-based language models, layer by layer, starting from the very basics: a bigram model.

Core Objectives: 

Build a transformer-based language model from scratch using PyTorch.

1. Understand and implement the components of the transformer architecture: self-attention, multi-head attention, positional encoding, and more.

2. Develop the model iteratively, starting with a basic bigram model and scaling toward GPT-like functionality.

3. Explore the computational and mathematical underpinnings of transformers.

4. Train the model on simple text data to test its generative capabilities.
